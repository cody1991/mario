## User Scenarios & Testing *(mandatory)*

### User Story 1 - 精准的碰撞检测体验 (Priority: P1)

玩家在游戏中移动和跳跃时，角色与地面、平台、砖块的碰撞检测准确无误。不会出现穿墙、卡墙、悬空站立等异常情况。碰撞边界与视觉效果一致，玩家能够直观判断是否能通过某个缝隙。

**Why this priority**: 碰撞检测是平台游戏的核心基础，直接影响游戏的可玩性和玩家信任度。当前版本存在碰撞问题，这是本次重构的首要目标。

**Independent Test**: 玩家可以在包含各种地形的测试关卡中自由移动，验证所有碰撞场景都能正确处理。

**Acceptance Scenarios**:

1. **Given** 马里奥快速向墙壁移动, **When** 接触墙壁, **Then** 马里奥立即停止且不会穿入墙体
2. **Given** 马里奥从高处下落, **When** 落到平台上, **Then** 马里奥稳定站在平台表面，不会陷入或弹跳
3. **Given** 马里奥站在平台边缘, **When** 向外移动一小步, **Then** 马里奥自然掉落，不会卡在边缘
4. **Given** 马里奥从下方跳跃撞击砖块, **When** 头部接触砖块, **Then** 马里奥立即开始下落，不会卡住
5. **Given** 马里奥在两个砖块之间的缝隙, **When** 缝隙宽度大于马里奥宽度, **Then** 马里奥可以顺利通过

---

### User Story 2 - 流畅响应的操控手感 (Priority: P1)

玩家按下方向键或跳跃键时，角色立即响应，移动和跳跃动作流畅自然。加速、减速、转向都有合理的物理手感，既不会太滑也不会太生硬。跳跃高度可控，长按跳跃键可以跳得更高。

**Why this priority**: 操控手感是玩家体验的核心，与碰撞检测同等重要。良好的操控让玩家感到角色是自己的延伸。

**Independent Test**: 玩家可以在空旷场地反复测试移动和跳跃，验证操控响应及时、手感舒适。

**Acceptance Scenarios**:

1. **Given** 马里奥静止, **When** 玩家按下方向键, **Then** 马里奥在 50 毫秒内开始移动
2. **Given** 马里奥在移动, **When** 玩家松开方向键, **Then** 马里奥平滑减速停止（有适度惯性）
3. **Given** 马里奥向右移动, **When** 玩家按下左方向键, **Then** 马里奥快速转向，不会滑行过远
4. **Given** 马里奥在地面, **When** 玩家短按跳跃键, **Then** 马里奥进行小跳
5. **Given** 马里奥在地面, **When** 玩家长按跳跃键, **Then** 马里奥进行高跳，高度明显大于小跳
6. **Given** 马里奥在空中, **When** 玩家按方向键, **Then** 马里奥可以在空中调整水平方向

---

### User Story 3 - 敌人交互的准确判定 (Priority: P2)

玩家与敌人的碰撞判定准确。从上方踩踏敌人时，敌人被消灭且马里奥弹跳；从侧面或下方接触敌人时，马里奥受伤。判定边界清晰，不会出现明明踩到了却受伤的情况。

**Why this priority**: 敌人交互是游戏挑战性的来源，准确的判定让玩家感到公平。依赖于碰撞系统的完善。

**Independent Test**: 玩家可以在有敌人的场景中反复测试踩踏和碰撞，验证判定一致且符合直觉。

**Acceptance Scenarios**:

1. **Given** 马里奥从敌人正上方下落, **When** 落到敌人头上, **Then** 敌人被消灭，马里奥弹跳
2. **Given** 马里奥从敌人斜上方下落, **When** 接触敌人顶部区域, **Then** 仍判定为踩踏成功
3. **Given** 马里奥从侧面接触敌人, **When** 碰撞发生, **Then** 马里奥受伤并进入无敌状态
4. **Given** 马里奥刚踩踏敌人弹起, **When** 立即接触另一个敌人, **Then** 可以连续踩踏

---

### User Story 4 - 稳定流畅的游戏性能 (Priority: P2)

游戏在各种设备上都能保持稳定的帧率，画面流畅无卡顿。即使场景中有大量敌人和物体，游戏也能正常运行。

**Why this priority**: 性能是游戏体验的基础保障，使用游戏引擎应该带来性能优化。

**Independent Test**: 在不同设备和浏览器上运行游戏，验证帧率稳定。

**Acceptance Scenarios**:

1. **Given** 游戏正在运行, **When** 场景正常, **Then** 帧率保持在 60 FPS
2. **Given** 场景中有 20 个以上敌人, **When** 游戏运行, **Then** 帧率不低于 30 FPS
3. **Given** 游戏运行超过 10 分钟, **When** 持续游玩, **Then** 无内存泄漏导致的性能下降

---

### User Story 5 - 保持原有游戏功能 (Priority: P3)

重构后的游戏保留 V1 版本的所有功能：关卡场景、金币收集、分数系统、生命系统、胜利/失败状态、暂停功能等。玩家体验到的游戏内容与之前一致。

**Why this priority**: 这是重构而非重做，需要确保功能完整性。在核心体验改善后再验证功能覆盖。

**Independent Test**: 完整游玩一局游戏，验证所有原有功能正常工作。

**Acceptance Scenarios**:

1. **Given** 游戏加载完成, **When** 玩家开始游戏, **Then** 显示完整的关卡场景
2. **Given** 马里奥接触金币, **When** 收集金币, **Then** 金币消失、播放音效、分数增加
3. **Given** 马里奥死亡, **When** 生命值归零, **Then** 显示游戏结束界面
4. **Given** 马里奥到达终点, **When** 触发胜利条件, **Then** 显示胜利界面和最终分数
5. **Given** 游戏进行中, **When** 玩家按暂停键, **Then** 游戏暂停并显示暂停界面

---

### Edge Cases

- 马里奥在移动平台上时，应随平台一起移动（如有移动平台）
- 马里奥同时接触多个敌人时，只触发一次伤害判定
- 马里奥在极窄通道中移动时，不会卡住
- 高速移动时不会穿过薄墙（隧道效应）
- 游戏窗口大小改变时，画面正确适配
- 低帧率情况下，物理模拟仍然稳定（固定时间步长）

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 游戏 MUST 使用成熟的 2D 游戏引擎进行开发
- **FR-002**: 游戏引擎 MUST 提供可靠的物理碰撞系统
- **FR-003**: 碰撞检测 MUST 准确处理角色与静态地形的交互
- **FR-004**: 碰撞检测 MUST 准确处理角色与动态物体（敌人、道具）的交互
- **FR-005**: 角色操控 MUST 响应及时，输入延迟不超过 50 毫秒
- **FR-006**: 角色移动 MUST 具有平滑的加速和减速曲线
- **FR-007**: 跳跃 MUST 支持可变高度（短按低跳、长按高跳）
- **FR-008**: 踩踏敌人判定 MUST 基于接触角度和速度方向
- **FR-009**: 游戏 MUST 保持 60 FPS 的目标帧率
- **FR-010**: 游戏 MUST 使用固定时间步长进行物理更新
- **FR-011**: 游戏 MUST 保留 V1 版本的所有游戏功能
- **FR-012**: 游戏 MUST 支持键盘控制（方向键/WASD + 空格）
- **FR-014**: 输入系统 SHOULD 预留触控支持扩展点（代码注释标记 `// TODO: 移动端触控支持`）
- **FR-013**: 游戏 MUST 在主流浏览器中正常运行

### Key Entities

- **Player（玩家角色）**: 由玩家控制的马里奥，具有物理属性（位置、速度、加速度）、状态（站立/移动/跳跃/受伤/死亡）、碰撞体
- **Level（关卡）**: 游戏场景，包含地形瓦片、实体生成点、边界定义
- **Tile（瓦片）**: 构成关卡的基本单元，具有碰撞属性（实心/可穿透/单向平台）
- **Enemy（敌人）**: 可伤害玩家的 NPC，具有 AI 行为、碰撞体、可被踩踏区域
- **Collectible（收集物）**: 金币等可收集道具，具有触发区域
- **PhysicsWorld（物理世界）**: 管理所有物理实体和碰撞检测

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 碰撞检测准确率达到 100%，无穿墙、卡墙、悬空现象
- **SC-002**: 玩家操作响应延迟不超过 50 毫秒
- **SC-003**: 游戏在标准设备上保持 60 FPS 稳定帧率
- **SC-004**: 踩踏敌人判定符合玩家直觉，误判率低于 5%
- **SC-005**: 游戏加载时间不超过 3 秒
- **SC-006**: V1 版本的所有功能在重构后正常工作
- **SC-007**: 玩家在 5 分钟内能够适应新的操控手感
- **SC-008**: 游戏支持 Chrome、Firefox、Safari、Edge 浏览器

## Assumptions

- **确认使用 Phaser.js 作为游戏引擎**（成熟的 2D HTML5 游戏框架，内置 Arcade Physics 物理引擎，社区活跃，文档完善）
- 本次重构仅支持键盘控制，移动端触控支持作为后续版本功能（代码中预留扩展注释）
- 保留现有的美术资源和音效资源
- 保留现有的关卡设计和数据结构
- 重构后的代码结构可能与 V1 不同，但对外表现一致
- 不增加新的游戏功能，专注于改善核心体验
- 开发环境仍为纯前端，无需后端服务
